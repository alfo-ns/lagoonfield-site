# LagoonField

Sito statico LagoonField: HTML, CSS, JavaScript e asset, senza compilazione o dipendenze.

## Sito pubblico

https://alfo-ns.github.io/lagoonfield-site/

GitHub Pages pubblica il contenuto della radice del branch `main`. Il file `.nojekyll` consente di servire direttamente i file statici. Ogni push su `main` aggiorna il sito.

## Aggiornamenti

1. Modifica i file HTML, `styles.css`, `app.js` o gli asset.
2. Mantieni i collegamenti relativi per supportare la sottocartella `/lagoonfield-site/`.
3. Crea un commit e invialo a `main`.
4. Controlla il completamento del deploy nella scheda Actions del repository.

Vedi `LEGGIMI-DEPLOY.md` per i dettagli sul video, i contenuti e il modulo contatti.
